前天晚上，一个做独立开发的朋友发微信找我，语气里全是沮丧。

他花了整整三个月，用 Cursor 和 Claude 搓出来一个记账 App。界面精美，功能丝滑，甚至连暗黑模式和自动分类都做到了极致。

但在 Product Hunt 和即刻上线两周，只换来 3 个下载，其中 2 个还是他爸妈。

他问我：“阿荒，我是不是该去学学投流？还是我的 SEO 没做好？或者我干脆换个赛道？”

我看着他发来的那一连串“备选学习清单”——从 TikTok 运营、SEO 技巧到最新的增长黑客指南，叹了口气。

我没直接回他。因为我觉得，他的问题根本不是缺某个特定技能，更不是不够努力。

而是他被“正确答案太多”给困在原地了。

在这个技术狂飙的时代，我们最不缺的就是新的风口和工具。

今天有人说 Vibe Coding 是未来，明天有人说独立开发已经卷成红海；今天有人说必须做个人 IP，明天又说内容平台的流量红利已经彻底结束。

你刚把 Cursor 摸明白，Claude Code 又进化了。你刚跟上 Next.js 15 的步伐，新框架又在路上了。

不是哥们，这到底还让不让人活了？？？

![](/images/read-human-nature-fig1.png)

选项越多，越容易僵住。很多时候，我们不是不聪明，而是被潮水般涌来的“必学清单”按在了原地。

我不禁在想，在这个瞬息万变的时代，到底有没有一种东西是不会过期的？

它不是某个软件的快捷键，不是某个模型的 Prompt，不是某套短期的流量套路，而是一个无论技术怎么变，都能让你在写作、做产品、做销售时顺手得多的底层能力。

我越来越觉得，这个能力就是：**读懂人**。

读懂人怎么注意一件事，怎么相信一个人，怎么被一句话打中，怎么愿意往前迈出第一步。

这听起来像是一句老生常谈的鸡汤，但实际上，它是最冷酷的商业逻辑。

无论你做任何事，终点线后面站着的都是人。

你写代码，最后得有人愿意用；你做产品，最后得有人掏钱包；你写文章，最后得有人停下来读；你甚至只是想找份好工作，面试你的也依然是人。

那些你引以为傲的“硬技能”——写 Python、剪视频、做 Next.js 页面——当然重要。

但它们只是武器。你真正需要修炼的内功，是知道什么时候拔刀、朝哪里砍，以及对方为什么愿意因为你这一刀而往前走一步。

大部分产品之所以死掉，不是因为功能不够多，而是用户觉得“这跟我无关”。大部分表达没人听，不是逻辑不够，而是你没有先碰到对方脑子里那根绷紧的弦。

在 Dan Koe 的理论里，人的大脑是一台“故事引擎”，它有三根非常敏感的弦。只要你能碰到其中任何一根，对方的注意力就会被不由自主地吸引。

### 第一根弦：安全感（Survival Tension）

我们的大脑天生就有极其灵敏的威胁检测机制。虽然我们现在不用面对野兽了，但现代生活里的“生存威胁”无处不在：存款余额、职业天花板、孩子的教育、突然发现自己在公司里变得可替代。

为什么很多能让你停下来的文章，开头都不讲大道理，而是直接把一个隐隐作痛的问题说出来？

比如：“你是不是也发现，自己越努力，反而越没有安全感？”

这句话不是什么高深的信息，它像一只手，直接按在了你胸口最闷的那个地方。

尤其是这两年，大家表面上在热烈讨论 Claude Code、Sora、智能 Agent，但藏在所有理性探讨底下的，其实是同一个细微而焦虑的声音：

*“我还值钱吗？”*

这就是生存张力。

### 第二根弦：身份认同（Identity Tension）

人不只想解决问题，我们还极度渴望确认自己是谁。

我们是“拥抱 AI 的先锋”，还是“坚守人文底线的创作者”？我们是“追求效率的程序员”，还是“按部就班的打工人”？

一旦身份这个东西被触碰，人会变得极其敏感。你说某个方案不好，大家可以坐下来理智讨论；但如果你说他这“类”人不行，他马上就会和你急。

互联网上关于 AI 的争吵就是最典型的例子。有人把自己代入到“AI 降临派”，有人则抱团成为“卢德主义者”，双方互相扔石头，简直像两派新宗教的交锋。

因为当一个工具开始威胁到谋生方式时，它碰到的不仅仅是你的钱包，更是你的职业尊严，和你过去十年积累的自我价值。

所以，一个聪明的表达者不会只机械地推销“这个工具效率更高”。

他会转而说：“如果你不想在未来变成一个只会执行指令的机器人，你需要重新训练自己的判断力。”

你看，这就不再是讲功能了，而是在照镜子，照出你的身份。

### 第三根弦：进展感（Progress Tension）

在安全感被满足、身份被接住之后，人必然会产生向上的渴望——我们想成为更好的自己。

真正优秀的产品和内容，卖的都不是功能，而是“转化的可能”。

它不只告诉你“我能帮你省下 10 分钟”，而是告诉你“你终于可以把生活的掌控权拿回来一点了”。

但现实是，很多人明明收藏了一堆“人生跃迁”的教程，却从来不打开。

因为他不需要第 101 个宏大的理论。

他需要的是一个极其具体、小到几乎没有摩擦力，但做完能让他产生下一步冲动的起点。

很多创作者最容易犯的错误就是给的答案太大。你要建立个人品牌，你要做长期主义，你要提升认知。

这些词都对。但一个加班到深夜十一点半、坐在地铁上手机电量只剩 12% 的人，看到这些宏大词汇，他只会觉得疲惫。

他真正需要的是什么？是“今晚不要看任何教学视频，只写下你今天遇到的 3 个具体麻烦。明天挑一个，写 200 字记录下来”。

就这么小。但它能启动。

![](/images/read-human-nature-fig2.png)

我始终坚信，好的表达不是为了把人震住，而是为了把人往前推半步。

这种通过洞察人心、寻找张力来促成行动的技艺，其实有一个很古老的名字：**修辞（Rhetoric）**。

在古希腊的广场上，修辞曾经是一门核心的公共技艺。如果你想说服公民，想让大家听懂你的政策并付诸行动，你就必须深刻理解人是如何被语言、情感和逻辑影响的。

这绝不是什么投机取巧的小聪明，而是公共生活的基础能力。

可惜的是，后来我们把这个词变窄了，变成了语文课本上的比喻、排比和拟人；再后来，互联网把这个词变脏了，变成了标题党、转化率、私域成交和“韭菜收割术”。

我知道，一提到“说服”、“影响”、“心理按钮”，很多人会本能地产生反感。

说实话，我也反感。因为现在的中文互联网上，充斥着“开口闭口是痛点，转过身来卖课，最后甩出付款码”的套路。

但工具本身是无罪的。刀可以用来切菜，也可以用来伤人。

理解人性不是为了去操控别人，而是一种更深的责任。

如果你真的知道人会被什么困住、被什么激发，你就更应该保持敬畏，而不是为了点击率去无节制地拧那根最痛的弦。

一个诚实的创作者，应该做到八个字：**说出痛苦，给出出路**。

不是夸大痛苦，也不是伪造出路。这个边界很细，但决定了你是一个活生生的人，还是一个算法的提线木偶。

![](/images/read-human-nature-fig3.png)

顺着这个逻辑，我们到底该怎么训练这个“读懂人”的超能力？

不需要去死背心理学教材，也不需要报什么写作课。在日常里，你只需要刻意练习这三件事：

#### 一、 刻意留意自己的“被动停留”

不要只看冷冰冰的数据（点赞数、转发数），去观察你和身边人的真实行为。

下次你刷手机，突然被某个视频、某篇文章吸引停下来时，别急着划走，花 30 秒分析一下自己：
1. **它戳中了我的哪根弦？**（安全感、身份、还是进展感？）
2. **它是怎么开头的？** 它是不是用了“如果你是……”（Mirror the Identity）来定位我？或者用了一个“没有人知道……”（Name the Threat）来制造悬念？
3. **它是在帮我解决问题，还是在纯粹消耗我的焦虑？**

把这些打动过你的开头句式记录下来。这些都是前人测试过千百遍的“人性钥匙”。

#### 二、 用“小切口”去呈现真实问题

写东西、做产品时，试着把抽象的概念翻译成具体的场景。

比如，不要说“AI 会提高工作效率”，说“以前写一段 CRUD 代码要两小时，现在用 Claude Code 只要两句指令，剩下的一小时四十分钟，你打算用来干嘛？”。

练习去写你每天最真实的烦恼，哪怕它很微小。

因为真实的痛苦往往不是宏大的叙事，而是藏在生活指甲缝里的倒刺。你把自己指甲缝里的倒刺说清楚了，十万个有同样倒刺的人就会向你靠拢。

#### 三、 小步快跑，丢进真实的池塘里激起水花

想知道自己是不是真的懂人，最简单的方法就是扔一个东西到市场里。

不要憋大招。不要花三个月去写一篇万字长文或者开发一个完美产品。

写一个 200 字的想法，发到朋友圈、即刻或者微博；做个最简陋的 Demo，给身边的三个朋友用。

看他们是真的被触动了、转发了，还是只是出于礼貌给你点了个赞。

真实的市场有时候很冷酷，但它最诚实。它会逼你回答那个最残忍的问题：

*“别人凭什么要在乎？”*

这个问题很残酷，但也很公平。

技术迭代的速度，已经快到了让人产生眩晕感的程度。

当 Claude Code 可以帮你重构项目，Codex 可以帮你改 Bug，Sora 可以帮你生成高清视频时，纯粹执行层的门槛正在以每天为单位往下降。

这意味着，在不久的将来，堆砌功能、快速产出内容的能力将不再稀缺。

相反，最稀缺的会是这几件事：
- 你能不能判断一个活生生的人，在当下的真实处境里需要什么？
- 你能不能把一个混乱的问题，用有温度的语言说清楚？
- 你能不能在满屏都是 AI 自动生成的冰冷世界里，让别人隔着屏幕感觉到，对面站着的是一个有体温、有故事、会脆弱的活人？

这可能就是未来很长一段时间里，最值钱，也最不该只为了钱去学的能力。

别追风口了。

风口总会停，但人性的潮汐，从未变过。

我后来把这些话发给了那个做独立开发的朋友。

他说：“懂了，我下一步不是去学投流，而是去找十个记账用户聊聊天。不推销产品，就听他们抱怨平时是怎么记账的。”

我说：“这就对了。”
